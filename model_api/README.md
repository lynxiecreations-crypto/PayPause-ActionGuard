# PayPause inference API

This API loads the TF-IDF + Logistic Regression baseline generated by `ml/train_evaluate.py`.

- `GET /health`: reports whether the trained artifact loaded.
- `GET /metrics`: returns held-out evaluation metrics.
- `POST /predict`: accepts `{"text":"..."}`, returns the baseline model class/score and a separate list of transparent risk signals.
- Message content is processed in memory and not intentionally stored or logged by the application.
- CORS allows the public PayPause demo and local development.

## Honest scope
The UCI dataset is general English SMS spam, not an Indian financial scam corpus. Model score is not a calibrated fraud probability. Rule-based signals are not ML predictions. Never describe this as a production-grade UPI scam detector.
